# 눈치패스 인기 순위 서버

기존 콘텐츠와 이미지, 게임을 유지하고 TOP 10에 공용 열람 집계를 연결합니다.

- 방문자별 같은 글은 한국 시간 기준 하루 1회 집계합니다.
- 최근 7일은 오늘과 이전 6일, 최근 30일은 오늘과 이전 29일입니다.
- 전체 기간은 서버 집계 시작 이후의 기록입니다. 기존 브라우저 기록은 합치지 않습니다.
- 브라우저에 무작위 방문자 ID를 저장합니다. 이름, 이메일, IP 주소는 집계 DB에 저장하지 않습니다.
- 브라우저 저장소를 초기화하거나 다른 브라우저를 쓰면 다른 방문자로 집계됩니다. 인증된 분석 서비스 수준의 부정 집계 방지 기능은 아닙니다.
- 빈 순위와 서버 오류를 구분하며 예시 순위는 표시하지 않습니다.

## 로컬 실행

Node.js 22 이상에서 이 폴더에서 실행합니다.

```sh
npm ci
npm run build
npm start
```

브라우저에서 http://localhost:4173 을 엽니다. 로컬 조회 기록은 `.local-data/`에 보존됩니다. HTML 파일을 직접 열면 서버 API를 사용할 수 없습니다.

## Netlify 배포

기존 Netlify 프로젝트를 이 저장소에 연결합니다. 빌드 명령과 공개 폴더는 `netlify.toml`에 설정되어 있습니다. Netlify Database는 패키지를 감지하여 생성하고 SQL 마이그레이션을 적용합니다. 데이터베이스와 함수는 계정의 사용량에 포함됩니다.

Netlify는 기존 URL을 유지합니다. GitHub Pages는 루트의 기존 HTML을 그대로 사용하며, Netlify는 빌드 중 공용 인기 순위를 연결한 `public/index.html`을 생성합니다. 이미지 바이트와 글 내용 및 게임 payload는 수정하지 않습니다.

`.netlify/`, `.local-data/`, `node_modules/`, `public/`는 커밋하지 않습니다. 서버 소스와 DB 연결 정보는 공개 폴더 밖에 있습니다.
